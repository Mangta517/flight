# 飞行器项目（四轴无人机） — 组合仓库

一个仓库管理 **飞控端** 与 **遥控端** 两套工程。

```
flight/                      ← 仓库根
├── flight_hal/              ← 飞控端 (STM32F103 姿态/定高/电机控制)
│   └── MDK-ARM/application/ ← 飞控应用代码 (PID/混控/遥控处理)
└── flight_remote_hal/       ← 遥控端 (摇杆/按键/SPI 通信)
    └── MDK-ARM/application/ ← 遥控应用代码
```

> 飞控端源码注释里已保留更详细的调参过程与推断，这里作汇总。

## 二、调参问题与调试记录

> 调参仍在进行。以下记录是判断符号/量级的依据，多为 2026 年二分法调试验证。

### 1. 持续前漂 —— 俯仰配平角 `PITCH_TRIM_DEG = 4.0f`（°）

原理：推力带前向分量 → 机头抬起使推力后倾，抵消前漂。不同于电机转速微调，角度配平会改变姿态环参考、不会被姿态环吸收。

方向：正值 = 机头抬起（抵消前漂）。若前漂加剧说明符号反了，取反即可。

| 实验值 | 现象 |
|--------|------|
| 2.0° | 无效（当时未烧新固件） |
| 8.0° | 配平生效但过大，变向后漂（方向正确） |
| 3.0° | 仍向前漂（平衡点约在 3~8 之间） |
| **5.5°** | **当前值，二分法中值** |

下一步：若 5.5° 后漂 → 改 4~5°；仍前漂 → 改 6~7°。

> ⚠️ 注意：若根因是校准面不水平 / 摇杆中位偏移 / **IMU 装向错误**，配平只能掩盖症状，需根治。

### 2. 横滚漂移 —— `ROLL_TRIM_DEG = 3.0f`（°）

方向：左漂先试正值；若左漂加剧或变右漂则取反（负值）。

| 实验值 | 现象 |
|--------|------|
| +3.0° | 左漂加剧，横滚角增大（方向反） |
| +7.0° | 仍左漂加剧（确认方向反） |
| **-7.0°** | **方向取反；若变右漂往小调 -3~-5** |

> 注：源码当前宏写为 `3.0f`，与"改为负值取反"的记录存在出入——**实际调参以试飞现象为准**，此处仅为历史记录。

### 3. 电机转速补偿（当前全部清零做对照）

| 宏 | 作用 | 值 |
|----|------|----|
| `MOTOR_TOP_TRIM` | 前电机额外补偿 | 0 |
| `MOTOR_LEFT_TOP_TRIM` | 左前电机额外补偿 | 0 |
| `MOTOR_RIGHT_TOP_TRIM` | 右前电机额外补偿 | 0 |

历史：右前原值 12 导致右前总补偿 24、比左前（14）多 10，左侧升力偏小 → 飞机左漂；先改 2 与左前对称，现一并清零对照。若清零后明显漂移，说明原值在补偿真实重心/动力偏差，再按需调回。

> 用于排查"P=0 仍前漂"：是否与此微调有关。

### 4. 摇杆死区 `STICK_DEADZONE = 15`

量程 0~1000（中位 500），死区 15 ≈ 1.5%。消除中位微小偏移（如 PIT 中位 505~520）导致的持续单向漂。

### 5. 电机限速 `APP_FLIGHT_MOTOR_MAX_SPEED = 1000`

0~1000 = 0~100% 占空比（原 400 = 40%）。**放开后动力大幅增强，务必先卸桨测试！**

### 6. 偏航正反馈 —— `yaw_out` 取反

实机桨/电机转向与混控假设相反，导致偏航正反馈（起飞后越转越快）。代码中 `yaw_out = -gyro_z_pid.output` 取反恢复负反馈。若改后反而不稳，说明问题在电机通道映射。

### 7. 偏航零漂抑制（陀螺仪零点自校准）

偏航仅有陀螺仪积分、无绝对参考，残余零偏被积分放大。在 `IDLE`（未解锁、电机停转）且三轴角速度 < ~3°/s 时，累积 100 次读数取平均，累加进陀螺仪零点，收敛后 yaw 不再漂。手持转动（角速度大）立即复位，不会误校准。

## 三、X 型混控布局（机头 = TOP 侧）

```
                机头(前)
              ┌───────────┐
              │ LT     RT │   LT=left_top   TIM2_CH3 (PA2)
              │           │   RT=right_top  TIM2_CH2 (PA1)
              │ LD     RD │   LD=left_down  TIM2_CH4 (PA3)
              └───────────┘   RD=right_down TIM2_CH1 (PA0)
                机尾(后)
```

混控：`+pitch→前电机` `-pitch→后电机` `+roll→右电机` `-roll→左电机` `+yaw→对角配对`。
电机转向（俯视）：标准 X 布局为对角同向、相邻反向，按实际装桨确认。
